# 📊 Simulador de Classificação

Aplicação web desenvolvida para processar listas de candidatos e gerar automaticamente um ranking de classificação com base na nota final.

O projeto foi criado com o objetivo de praticar **JavaScript, manipulação do DOM, expressões regulares e ordenação de dados**.

## 🚀 Funcionalidades

* Inserção de listas de candidatos;
* Extração automática de nomes e notas;
* Identificação da nota final de cada candidato;
* Ordenação dos candidatos por nota;
* Geração dinâmica do ranking de classificação.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📸 Como utilizar

1. Acesse a aplicação;
2. Cole a lista de candidatos no campo de texto;
3. Clique em **"Gerar Ranking"**;
4. O sistema irá processar os dados e exibir a classificação em ordem decrescente de nota.

## 💻 Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

2. Acesse a pasta do projeto:


Este projeto foi desenvolvido como prática de **lógica de programação e manipulação de dados com JavaScript**, simulando um sistema de classificação de candidatos.
